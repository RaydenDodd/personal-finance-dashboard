# Consolidated investment analytics: reused and new functionality

For the current runtime path, caching, background worker and range-overlay storage (November 25, 2026), see [Investment analytics durable read model](INVESTMENT-READ-MODEL.md). This document describes the underlying calculation architecture.

The consolidated Investments layer reads existing portfolio records, including hidden broker mirrors. It does not change portfolio management, native account balances, net-worth inclusion, transaction processing, pricing, or lot accounting.

| Capability                                                           | Existing implementation reused                                                                                                                                         | Consolidation work                                                                                                                                                                                                 |
| -------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Portfolio ownership/visibility                                       | `Portfolios`, `BrokerPortfolioData`, existing `latestSnapshot`                                                                                                         | Ownership-scoped analytics filters include disabled portfolios independently of net worth.                                                                                                                         |
| Positions, quantities, remaining basis, current valuations and gains | `getHoldingValues`, existing holdings recalculation and gains calculator                                                                                               | Group already-calculated position values by stable instrument identity; sum valid remaining basis and divide by corresponding shares. Missing evidence remains null. No second FIFO engine.                        |
| Portfolio cash and source totals                                     | Authoritative `getPortfolioSummary` base-currency total, cash and quality outputs; existing `PortfolioBalances` conversion fallback only when display currency differs | Sum native summaries once, retain null evidence and do not add SimpleFIN account balances. Closed-position realized gains also come from the native summary. Preserve source dates and reconciliation differences. |
| Historical valuation                                                 | Existing `computeHoldingsValueByDate`, `accumulateCashDeltas`, `computePortfolioCashByDate`, persisted `SecurityPricing`                                               | Consolidated adapter supplies selected portfolios. Suppress missing-price/FX fallback values; incomplete imported histories use actual dated broker observations only.                                             |
| External funding                                                     | Existing `PortfolioTransfers` and contribution boundary rules                                                                                                          | Selected-group membership determines internal versus external transfers, excluding adjustments. Buying securities and dividends never become contributions.                                                        |
| Market data                                                          | Existing `SecurityPricing`, provider metadata, scheduled jobs and manual price-sync endpoint                                                                           | Read provenance and freshness. No new scheduler or pricing pipeline.                                                                                                                                               |
| Dividends                                                            | Existing investment dividend transactions                                                                                                                              | Group actual records and distinguish unavailable interest/reinvestment/forecast metadata.                                                                                                                          |
| TWR/XIRR and comparisons                                             | Existing portfolio return behavior inspected                                                                                                                           | New consolidated, availability-gated calculations require complete flow/value coverage. Existing approximation paths are not relabeled as verified consolidated returns.                                           |
| Fund look-through, overlap and classifications                       | No existing equivalent found                                                                                                                                           | New recursive exposure/overlap calculations and separate append-only, owner-scoped composition snapshots; no trades, tax lots or direct holdings are created.                                                      |
| Benchmark comparison                                                 | Persisted security price history                                                                                                                                       | New normalized common-date comparison, explicitly price-only unless actual total-return data exists.                                                                                                               |

All frontend pages and dashboard widgets share the same response contract and query cache. Unsupported calculations are explicit unavailable metrics with reasons. Known-value subtotals are separately labeled partial when full totals cannot be established. Composition imports append immutable source snapshots; repeated identical imports are idempotent and conflicting source revisions require a distinct source/date identity. Exact UUID/ISIN/CUSIP aliases resolve to held instruments when unique, preserving original identifiers and avoiding ticker-only merges. Incompatible or unspecified sector/industry taxonomies retain explicit labels instead of silently mixing.

The exact-boundary consolidated-return engine supports chained TWR, annualized XIRR through the existing `xirr` library, drawdown and sufficiently sampled daily volatility. Its live adapter withholds results without complete flow history and actual required boundary valuations; it never replaces missing values with the native historical approximation. Current imported broker histories are incomplete. Announced future dividends, verified dividend-reinvestment flags, standalone interest attribution, automatic composition downloads and total-return benchmark history are unavailable in the existing data. Their interfaces explain the missing coverage. Manual composition imports and persisted price-only benchmark comparison are supported.
